Cómo funciona la sincronización

Esta aplicación utiliza Material 3 que genera variables CSS del sistema (con el prefijo --mat-sys-*). A través de Tailwind v4, hemos mapeado estas propiedades directamente en la directiva @theme, lo que nos permite usar clases de Tailwind nativas sincronizadas con el tema de Angular Material.

Variables de Color Activas
--mat-sys-primary
--mat-sys-tertiary
--mat-sys-surface
--mat-sys-background
Mapeo de Clases Tailwind
bg-primary → aplica color de la variable principal
text-tertiary → aplica color de la variable terciaria
border-outline → color de bordes del sistema M3
font-brand → usa la tipografía premium Outfit
star
Efectos Premium Activos

El tema predeterminado es Oscuro. Al cambiar a modo claro desde la esquina superior derecha, se actualiza el tag color-scheme, lo que actualiza de manera nativa elementos del sistema como el scrollbar, inputs de fecha y fondos por defecto de forma instantánea.
